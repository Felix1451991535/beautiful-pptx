# 国赛金奖风 / Competition Gold

## 风格ID
`guosai` · 代码 `scripts/styles/guosai.py` · 示例 `styles/guosai/20261004-风格-国赛金奖.pptx`（7 页）· 总览 `styles/guosai/总览.png`

## 风格描述
- 大学生创新大赛（互联网+ / 挑战杯 / 创青春）路演金奖模板的共同语言：**满版大照片 + 书法感金色大标题（带光）+ 整套统一的深色主色调**。
- 参考 `refs/user/guosai-1/2/3.png`（"慧瞰农域"深绿 + 无人机、"国赛科技"深蓝、"梨园记"酒红）。本库取其骨架，去掉了参考图里过满的装饰（标签条、编号圆、图标阵）。

## 适用主题
互联网+/挑战杯/创青春路演与答辩、乡村振兴/智慧农业/环保（深绿）、科技成果/工程（深蓝）、非遗/文化/文旅（酒红）、政务/单位汇报的"有气势"版本。
**不适用**：日常例会、轻松分享（太隆重）；英文场合（书法标题没有意义）。

## 设计令牌（配色）—— `new(scheme="green"|"blue"|"wine")`
| 角色 | 深绿（默认） | 深蓝 | 酒红 | 用在哪 |
|---|---|---|---|---|
| 底色 | `#05241A` | `#061630` | `#2A0A10` | 纯色页底、照片压暗、渐变 |
| 面板 | `#0A3626` | `#0B2448` | `#3D1119` | 少量底板 |
| 照片统一色调 | `#0E3B2A` | `#0D2A57` | `#4A1420` | `grade(tint=..., tint_amt=0.38)` |
| 弱化字 | `#A7BFB1` | `#A9B7CF` | `#CFB0B3` | 说明、信息行 |
| **金（唯一强调）** | `#E2BE6A` | 同 | 同 | 关键数字、细线、图表最高项 |
| 亮金（标题） | `#F6E3AE` + 金色外发光 | 同 | 同 | 书法标题 |
| 正文 | `#E6E2D6` | 同 | 同 | 正文 |

**强调色规则**：金色只给 书法标题 / 关键数字 / 0.75–1pt 细线；不做金色大色块、不做金色渐变边框。

## 字体（注明是否自带）
| 用途 | 首选 | 是否自带 | 回退 |
|---|---|---|---|
| 书法标题 | **华文行楷** STXingkai | **随 Microsoft Office 安装，Windows 本身不带**（无 Office 的电脑会被替换） | **楷体** KaiTi（中文版 Windows 自带）——把 `F_CAL` 改为 `F_CAL_FALLBACK` |
| 备选标题 | 方正姚体 FZYaoTi / 方正舒体 FZShuTi | 随 Office 安装，Windows 不带 | 楷体 |
| 备选标题 | 隶书 LiSu | 随 Office 安装，Windows 不带 | 楷体 |
| 正文 | **微软雅黑** | Windows 自带 | — |
| 数字 | **Bahnschrift** | Win10 1709+ 自带 | Segoe UI |

> 交付到评委电脑时：若不确定对方装了 Office 中文字体，在 PowerPoint "文件 → 选项 → 保存 → 将字体嵌入文件"（嵌入前确认该字体许可允许嵌入），或把标题改用楷体。预览替代：华文行楷/楷体→Ma Shan Zheng，方正姚体→ZCOOL XiaoWei，Bahnschrift→Barlow。

## 字号阶梯（pt）
mega 150（封面主标题 4 字）｜章节大字 200（2 字）｜display 88–96（结束页）｜h1 48–52（页标题，书法）｜数字 48–96｜h2 24–28｜lead 20–22｜body 16｜small 13–14

## 照片调色参数
`grade(..., sat=0.9, contrast=1.1, tint=主题色, tint_amt=0.38, vignette=0.35)` + PPT 内再叠一层底色 30–45% 透明矩形 + 一侧渐变压暗（`photo_bg(side="left"/"bottom")`）。
选图：航拍大场景（梯田、田野、城市、工厂）、无人机/设备特写、手部 + 作物；一套 deck 所有照片统一调成同一色调，这是"高级感"的关键。

## 纹理/装饰素材
| 素材 | 函数 |
|---|---|
| 金色镜头光条 | `light_streak("FFE2A0", alpha=0.55)`，放在书法标题后面 |
| 暗角 | `vignette_png(color=底色, strength=0.7~0.85)` |
| 纯色页光晕 | `glow_field([...深绿光斑...], base=底色)` |
| 标题发光 | `text_shadow(tb, blur=16, dist=0, color="F2C661", alpha=0.45)`（用 0 距离金色阴影模拟外发光，PPT/LibreOffice 都显示） |

## 版式系统（函数 → 构图 → 字数上限）
| 函数 | 构图 | 字数上限 |
|---|---|---|
| `cover(prs, title, sub, info[3], img, event)` | 满版照片左侧压暗 + 光条 + 150pt 金色书法标题 + 副标题 + 竖线分隔的信息行 | 标题 4 字（≤ 6）；副标 ≤ 20 字 |
| `pain(prs, heading, items[3], img)` | 左照片（渐变融入）+ 右"金色大数字 + 一句话"×3，细金线分隔 | 每句 ≤ 26 字 |
| `divider(prs, word, sub, img)` | 满版照片重压暗 + 200pt 两字书法 + 光条 | 2 字 |
| `solution(prs, heading, feats[3], img)` | 满版设备照片右侧露出，左侧三条"金色小标题 + 一句话" | 小标题 ≤ 6 字，说明 ≤ 22 字 |
| `data(prs, heading, big, label, cats, vals, note)` | 左大数字 + 说明；右柱状图（最高项金色，其余墨绿） | 类目 ≤ 6 |
| `gallery(prs, heading, items[3])` | 三张照片错落（中间高 0.3 英寸）+ 细金框 + 图注 | 图注 ≤ 12 字 |
| `closing(prs, line, sub, img)` | 满版照片 + 两行书法"谢谢聆听 恳请指导" | — |

## 禁止项
- 参考模板里常见但"AI 味"的元素：每页顶部小标签条 + 编号圆 + 图标卡片阵、满屏金色花纹边框、立体字、彩虹渐变。
- 同一 deck 混用两套主色；照片不统一调色；金色超过 3 处/页；书法字写长句（书法只写 ≤ 8 字的标题）。
- 正文用书法字体；正文 < 14pt。

## 调用示例
```python
import guosai as G
prs = G.new("blue")            # 深蓝科技版
G.cover(prs, "国赛科技", "一句话定位", ["赛道：…", "团队：…", "指导老师：…"], "/path/photo.jpg", "第 X 届 …")
G.F_CAL = G.F_CAL_FALLBACK      # 评委电脑可能没装 Office 字体时，改用楷体
```

## 已知局限
- 华文行楷不是 Windows 系统字体（Office 字体），见上文回退方案；预览用 Ma Shan Zheng，字形比华文行楷更"楷"、更规整。
- 参考图里的"抠图无人机/人物 + 前景遮挡标题"效果需要透明 PNG 素材，本库未做（可自行放置）。
- "外发光"用 0 距离阴影模拟，强度不如 PowerPoint 原生"发光"效果；需要更强可在 PowerPoint 里对标题加"发光：金色 18pt"。
