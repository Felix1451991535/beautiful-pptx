# 深色极光 / Aurora

## 风格ID
`aurora` · 代码 `scripts/styles/aurora.py` · 示例 `styles/aurora/20261004-风格-深色极光.pptx`（7 页）· 总览 `styles/aurora/总览.png`

## 风格描述
- 近黑的蓝紫底上，从画面边缘升起一团柔和的极光（青绿 → 紫 → 洋红），字是白色超大号，一页只说一件事——发布会的节奏。
- 光晕全部由程序生成（多椭圆高斯光斑 + 屏幕混合 + 可选竖向"帘幕"纹理 + 抖动防色带），不使用任何生成式图片。

## 适用主题
产品发布、科技/AI 主题演讲、年度战略、活动开场/倒计时、音乐会/晚会、大屏暗场演讲。
**不适用**：需要大量阅读的内容（深底小字很累）；白天明亮会议室投影仪（对比度不足时换 Glass）。

## 设计令牌（配色）
| 角色 | HEX | 用在哪 |
|---|---|---|
| 底色 | `#07080F` | 所有页底；光晕叠在其上 |
| 白字 | `#F4F6FB` | 标题、大数字 |
| 正文 | `#DCE1EC` | 副标题 |
| 弱化 | `#8E97AA` | 说明文字 |
| **极光青（唯一文字强调色）** | `#3CF0C5` | 顶部小字 meta、数字下方的单位/标签 |
| 光晕色（只在光里） | `#19E3B1` 青、`#6A4CFF`/`#8C6CFF` 紫、`#FF4FA3` 洋红、`#2D7BFF` 蓝 | 只用于背景光晕，不做文字和形状填充 |

**强调色规则**：文字里只有极光青一种彩色；大数字永远是白色（可加白→淡青的文字渐变，见 `grad_text`）。

## 字体（Windows 自带）
| 用途 | 西文 | 中文 |
|---|---|---|
| 大标题 | **Segoe UI Semibold** | **微软雅黑**（粗） |
| 大数字 | **Segoe UI Light** | 微软雅黑 |
| 正文/meta | **Segoe UI** | 微软雅黑 |

可选：数字用 **Bahnschrift**（Win10 1709+ 自带，DIN 风格）。预览替代：Segoe UI 各字重→Selawik 对应字重；微软雅黑→Noto Sans CJK（本机无 Light，预览中文略重）。

## 字号阶梯（pt）
mega 120（封面品名）｜display 80（一句话）｜数字 150–180（Light）｜h1 44–54｜lead 24｜body 15–18｜meta 12（字距 300）

## 照片调色参数
`grade(..., sat=0.7, contrast=1.15, bright=0.62~1.35, tint="1A2340", tint_amt=0.25)` —— 降饱和、偏冷蓝、按原片亮度调 bright。
产品照片右侧出血，左边用"底色 100% → 0%"的渐变矩形无缝融合；照片上不放小字。选图：深色背景产品照、低调光（low-key），**避免可见品牌 logo**。

## 纹理/装饰素材
| 素材 | 函数 | 说明 |
|---|---|---|
| 极光背景 | `glow_field(GLOWS[preset], base="07080F", curtains=0.18)` | 预设 `horizon`（底部极光带）/`center`（字后光）/`corner`/`left`/`dawn`；改颜色直接改 GLOWS 里的 HEX |
| 透明光晕 | `radial_glow("6A4CFF", 900, falloff, alpha)` | 叠在照片/纯底上的可移动光斑（不产生接缝） |
| 文字渐变 | `grad_text(tb, [(0,"FFFFFF"),(1,"9FF5DD")], 90)` | PowerPoint 完整支持；LibreOffice 预览会退化为纯色 |

## 版式系统（函数 → 构图 → 字数上限）
| 函数 | 构图 | 字数上限 |
|---|---|---|
| `cover(prs, title, sub, meta)` | 左下大品名 + 一句副标 + 顶部青色 meta；底部极光带 | 品名 ≤ 12 字符；副标 ≤ 14 汉字 |
| `statement(prs, line, sub)` | 居中一句话，背后紫色光晕 | ≤ 2 行 × 8 汉字 / 6 英文词 |
| `hero(prs, img, number, unit, desc)` | 左超大细体数字 + 青色单位 + 说明；右产品照片出血 | 数字 ≤ 3 字符，说明 ≤ 30 汉字 |
| `specs(prs, heading, items[3])` | 三组"数字/标签/一句话"，细竖线分隔，无卡片 | 每组说明 ≤ 16 汉字 |
| `photo_feature(prs, img, title, desc)` | 满版暗调照片 + 左侧渐变压暗 + 标题 | 标题 ≤ 2 行 × 7 汉字 |
| `date_price(prs, big, sub, meta)` | 居中超大日期/价格（渐变字）+ 底部极光 | — |
| `closing(prs, line, sub)` | 两行英文/中文口号 | ≤ 2 行 |

## 禁止项
- 光晕压在文字正下方造成对比不足（文字区底色亮度必须 < 25%）。
- 霓虹描边、发光边框、赛博网格、科技蓝圆点阵、玻璃卡片堆叠、编号圆。
- 一页超过 1 个主信息；正文 < 15pt；彩色文字超过一种。

## 调用示例
```python
import aurora as A
prs = A.new(); A.cover(prs, "Lumen One", "听见更少，感受更多。", "2026 秋季发布会")
A.GLOWS["mine"] = [(0.3, 1.0, 0.5, 0.2, "FF8A3D", 0.9, 0)]; A.statement(prs, "一句话", glow="mine")
```

## 已知局限
- 极光是位图背景（2400×1350），改颜色需改参数重新生成（< 1 秒）。
- 文字渐变在 LibreOffice/WPS 里可能显示为纯色；Keynote 导入正常。
- 预览中文用 Noto Sans CJK，Windows 下微软雅黑字面略窄。
