# 通透玻璃 / Glass

## 风格ID
`glass` · 代码 `scripts/styles/glass.py` · 示例 `styles/glass/20261004-风格-通透玻璃.pptx`（7 页）· 总览 `styles/glass/总览.png`

## 风格描述
- 浅色柔彩渐变（蜜桃、薰衣草、天蓝、薄荷）上漂着几个清晰的渐变球体，磨砂玻璃面板压在球体上，透出模糊的颜色。
- **磨砂实现**：PowerPoint 没有实时背景模糊，所以把"整页背景图"预先高斯模糊，按面板位置精确裁切成一张图放在面板处，再叠"白色 36% + 1.25pt 白色 75% 描边 + 淡紫色柔阴影"。照片页同理（模糊的是照片本身）。

## 适用主题
年度回顾、互联网产品/运营汇报、App/小程序介绍、轻商务数据页、校园社团招新、个人年终总结。
**不适用**：传统政务、学术答辩（显得"轻"）；暗场大屏（换 Aurora）。

## 设计令牌（配色）
| 角色 | HEX | 用在哪 |
|---|---|---|
| 底色 | `#F3F1FA` | 渐变底的基色 |
| 柔彩光斑 | `#FFD3C4` 蜜桃、`#CFC2FF` 薰衣草、`#B9E4FF` 天蓝、`#C9F2E1` 薄荷 | 只在背景（`PASTEL`） |
| 球体 | 紫 `#B9A8FF→#6A4CF0`、珊瑚 `#FFC2B0→#FF7A62`、水蓝 `#A8E6FF→#3FA9E8` | 背景球体（`ORBS`），每页 2–3 个 |
| 墨紫（标题） | `#26243B` | 标题 |
| 正文 | `#3B3955` | 正文 |
| 弱化 | `#6E6B86` | 说明 |
| **强调紫** | `#6A4CF0` | 关键大数字、图表最高项 |
| 次强调珊瑚 | `#FF8A73` | 只在球体里出现，不做文字 |
| 玻璃 | 白 `#FFFFFF` @36%，描边白 @75% | `glass_panel()` |

**强调色规则**：文字里只有墨紫和强调紫；其他颜色只活在背景里。

## 字体（Windows 自带）
标题 **Segoe UI Semibold** / **微软雅黑**；数字 **Segoe UI Light**（中文单位自动缩到 42% 并改常规字重，见 `num_unit`）；正文 **Segoe UI** / **微软雅黑**。

## 字号阶梯（pt）
display 54–60｜h1 36–44｜数字 120（主）/ 54（次）｜h2 26｜lead 18–20｜body 16｜meta 12

## 照片调色参数
`grade(..., sat=0.92, contrast=0.95, bright=1.06, lift=14, warm=-2)` —— 明亮、低对比、略冷。
选图：明亮办公/生活场景、天空云彩、柔焦散景；照片上的玻璃面板放在画面"安静"的区域（天空、墙面、虚化处）。

## 纹理/装饰素材
| 素材 | 函数 |
|---|---|
| 柔彩渐变底 | `glow_field(PASTEL, base="F3F1FA", mode="mix")` |
| 渐变球体 | `orbs(base_path, ORBS[kind])`，kind = cover/stat/chart/end，或自定义 `[(cx, cy, r, 亮色, 暗色)]` |
| 背景模糊版 | `blurred(path, radius=70)`（缓存，与原图同尺寸） |
| 玻璃面板 | `glass_panel(slide, bg_path, x, y, w, h, radius=0.3, alpha=0.36)` |

## 版式系统（函数 → 构图 → 字数上限）
| 函数 | 构图 | 字数上限 |
|---|---|---|
| `cover(prs, title, sub, meta)` | 左侧大玻璃压在右侧大球上 | 标题 ≤ 2 行 × 6 汉字 |
| `statement(prs, line, sub)` | 一块宽玻璃横跨两个球 | ≤ 12 汉字 |
| `stats(prs, heading, big1, big2, big3)` | 一大两小、不等大的三块玻璃 | 每块说明 ≤ 14 汉字 |
| `photo_glass(prs, img, quote, who)` | 满版照片 + 左下磨砂引语卡 | 引语 ≤ 30 汉字 |
| `chart(prs, heading, desc, cats, vals)` | 左标题/说明 + 右玻璃面板内柱状图（最高项强调紫，其余淡紫） | 类目 ≤ 6 |
| `photo_bg_center(prs, img, line, sub)` | 满版天空照片 + 居中磨砂面板 | ≤ 10 汉字 |
| `closing(prs, title, sub)` | 小玻璃压在中心球上 | — |

## 禁止项
- 一页超过 3 块玻璃；玻璃里再套玻璃；玻璃等宽等距排成一行（至少大小不同）。
- 科技蓝、霓虹描边、深色玻璃配深色字；把面板移动后不重新生成裁切（会"透错"位置）。
- 正文直接压在球体上（必须在玻璃里或纯渐变处）。

## 调用示例
```python
import glass as G
prs = G.new(); s, bgp = G.page(prs, "cover")
G.glass_panel(s, bgp, 1, 1.5, 6, 4)       # 任意位置的磨砂面板
G.title(s, 1.5, 2, 5, 1, "标题")
```

## 已知局限
- 磨砂是"预先模糊 + 裁切"模拟，**拖动面板后背景不会跟着变**；要移动请改坐标后重新运行函数。
- 不支持面板后面有动画元素的实时透出。
- 球体是位图；颜色/位置改 `ORBS` 后重新生成。
